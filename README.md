# Predictor Saber 11

Modelo de Machine Learning que estima el puntaje global de Saber 11 a partir del contexto del estudiante y lo publica como una página web estática (Netlify, desde GitHub).

Proyecto de clase del curso ML1, Universidad EAN (Bogotá). **En construcción:** el trabajo avanza en la rama `dev` y llega a `main` cuando esté verificado.
